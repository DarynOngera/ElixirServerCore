# Elixir Server Core

Elixir Server Core is a **minimal, production-grade server framework**
for building reliable, observable backend services.

This project is **not a web framework**.

It provides:
- OTP-first runtime
- Mandatory telemetry & metrics
- Supervised background workers
- A thin HTTP interface
- Clear extension points

Fork this repository to build:
- Media servers
- Document processors
- Webhook services
- Monitoring APIs
- Internal platforms

---

## Core Principles

1. **Supervision over configuration**
2. **Telemetry over logs**
3. **Workers over controllers**
4. **Failures are expected**
5. **Visibility is mandatory**

---

## What This Project Is Not

- Not Phoenix
- Not MVC
- Not batteries-included
- Not opinionated about domains

---

## Status

Early-stage framework under active design.
